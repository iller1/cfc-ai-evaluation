# CFC+HAWM Hosted Web Alpha

Public browser deployment for the CFC+HAWM evaluation chat.

## Boundaries

- Ordinary chat: `MODEL_REPLY_UNCHECKED / CFC NOT_CONNECTED_C2`
- Prepared CFC example: runs the existing frozen demonstrator case through `cfc-anchor 0.2.90rc1`
- Frozen wheel SHA256: `b3b1f11e060289afa4e7da61072f2c31be7f0da1786be90682ec307d4e1f5303`
- Engine SHA256: `77a7547c02ce4aac3d3abc759bbd266f4251de9149da2308454527c7f2dea5c0`

This hosted alpha currently supports Gemini BYOK for ordinary chat.
The API key is stored only in server memory for the browser session.
